# Forwiroh 0.1.4

Healthy idle TCP streams now stay open. The previous five-minute
application-idle cutoff is gone; a quiet stream lives as long as its QUIC
connection is healthy. QUIC keepalives run every 20 seconds and a 60-second
transport idle timeout still detects a dead peer, so stale sessions are never
kept forever. TCP half-close is preserved.

Peer dials are isolated per peer. A stalled handshake to one peer no longer
blocks connections to other peers, and shutdown cancels pending dials
immediately instead of waiting for the setup timeout.

Connection failures are now reported instead of only logged. Core events include
`connecting` and `connection_error` with the peer ID. `disconnected` now carries
the close reason and a `connected` flag that says whether another connection to
that peer remains active. Forward and SOCKS `tunnel_error` events identify the
peer and tunnel, so clients can explain a failure and decide when to reconnect.

Install the latest CLI on Linux, macOS or Android/Termux:

```sh
curl -fsSL https://github.com/trufae/forwiroh/releases/latest/download/install.sh | sh
```

On Windows PowerShell:

```powershell
irm https://github.com/trufae/forwiroh/releases/latest/download/install.ps1 | iex
```

Installers choose the architecture, pin one release and check the archive's
SHA-256 before replacing an existing executable. Downloads and installers have
checksums in `CLI-SHA256SUMS`.

`forwiroh-android-debug.apk` is an installable debug build of `apps/android`,
including arm64-v8a and x86_64 native libraries. It uses automatic debug signing;
no release signing key is needed. Smaller arm64-v8a and x86_64 debug APKs are
also included. Native libraries are compressed in the APK and extracted during
installation to keep downloads small. Their checksums are in `ANDROID-SHA256SUMS`.

The SwiftPM SDK archives and `SHA256SUMS` remain included, along with the
size-focused Rust builds using `-Oz`, full LTO, one code generation unit and
symbol stripping.
