# Forwiroh 0.1.5

Windows SwiftPM SDK builds now cover amd64 and arm64. The release workflow builds
the Rust static library on each native Windows runner, then tests the unpacked
SDK and an external Swift consumer. The complete SwiftPM package includes both
Windows libraries alongside the Apple, Linux and Android variants.

Nix users can build the CLI and enter a development shell through the new flake.
A NixOS module provides `programs.forwiroh` options to install the CLI and run its
daemon as a systemd service with a configurable user, device name and state
directory.

Maintainers can use `scripts/version.sh` to show the current version or update
the workspace, lockfile and application versions together. Release notes and
`scripts/check-release.py` remain required before tagging.
