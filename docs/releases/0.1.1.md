# Forwiroh 0.1.1

Adds `setPairingPolicy` to the Swift SDK and `pairing_policy` to the command API. Embedded applications can restrict newly paired peers before inviting or connecting. The policy takes effect when the peer is saved, before it can access services, in both pairing directions. Existing peer policies are preserved. Set the default after each open; it lasts until shutdown.

Includes the asynchronous teardown test correction from main. Packaged consumers use prebuilt Apple, Linux and Android libraries without Cargo or binding generation.

Apple static-library headers now live under `CForwiroh/`, so Xcode can combine this SDK with other binary Swift packages without duplicate `include/module.modulemap` outputs.
