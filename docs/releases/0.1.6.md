# Forwiroh 0.1.6

Forwarding now reports when the remote TCP connection is ready and includes the
failure stage when setup fails. Embedded clients can show the Forwiroh error
when their local socket closes. A server that no longer trusts a device reports
that pairing is required.

Forwiroh can retry forward setup on a fresh QUIC connection if a cached
connection stalls. It retries before forwarding TCP payload and keeps unrelated
streams open. An approved re-pair refreshes the saved addresses for the same
endpoint identity and preserves the peer's permissions.

Embedders can use the released SwiftPM binaries with the existing C ABI. The
new forwarding diagnostics are available through the Swift SDK's event stream.
