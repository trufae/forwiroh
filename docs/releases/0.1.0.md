# Forwiroh 0.1.0

First release of Forwiroh, with a reusable SwiftPM SDK for macOS, iOS, Linux,
and Android. Swift applications can embed the networking core without building
Rust or generating bindings.

The async API covers pairing and approval, peer permissions, TCP forwarding,
reverse forwarding, SOCKS, events, and VPN packet transport.

## Downloads

- `Forwiroh-0.1.0-swiftpm.zip`: complete offline SwiftPM package, including all
  prebuilt libraries. Unpack it and add its `Forwiroh` directory as a local
  Swift package dependency.
- `Forwiroh-0.1.0-swiftpm-remote.zip`: smaller package that downloads the binary
  assets from this release using verified checksums.
- `ForwirohApple.xcframework.zip`: macOS arm64/x86_64, iOS arm64, and iOS
  simulator arm64/x86_64 static libraries and headers.
- `ForwirohNative.artifactbundle.zip`: Linux arm64/x86_64 glibc and musl, plus
  Android arm64-v8a/x86_64 static libraries and headers.
- `SHA256SUMS`: SHA-256 checksums for the four ZIP assets.

Use a SwiftPM ZIP asset rather than GitHub's automatically generated source
archives. The source tag does not include the generated binary manifest.
Swift 6.2+ is required; deployment minimums are macOS 14, iOS 17, and Android API
28. Linux requires glibc 2.39 or musl on both architectures.

See the [integration guide](https://github.com/trufae/forwiroh/blob/v0.1.0/docs/swiftpm.md)
for pmai setup, persistent mobile identities, Android JNI initialization, and
the Android certificate verifier dependency.

## Validation and limitations

The release workflow runs Swift tests on macOS and Linux, builds external Swift
consumers, and checks iOS and Android cross-compilation. Android device runtime
testing remains outstanding. The host application owns system VPN integration
and background services; this release does not include signed application
installers.
