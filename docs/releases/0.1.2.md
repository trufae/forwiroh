# Forwiroh 0.1.2

Standalone CLI downloads now cover Linux, Android, macOS and Windows, with
x86_64 and arm64 executables for each platform. Linux binaries are statically
linked with musl, including the Linux arm64 build. Windows uses an owner-only
named pipe for local daemon control and supports interactive pairing approval.

Install the latest CLI on Linux, macOS or Android/Termux:

```sh
curl -fsSL https://github.com/trufae/forwiroh/releases/latest/download/install.sh | sh
```

On Windows PowerShell:

```powershell
irm https://github.com/trufae/forwiroh/releases/latest/download/install.ps1 | iex
```

Installers choose the architecture, pin one release and check the archive's
SHA-256 before replacing an existing executable. Downloads and installers have
checksums in `CLI-SHA256SUMS`.

`forwiroh-android-debug.apk` is an installable debug build of `apps/android`,
including arm64-v8a and x86_64 native libraries. It uses automatic debug signing;
no release signing key is needed. Smaller arm64-v8a and x86_64 debug APKs are
also included. Native libraries are compressed in the APK and extracted during
installation to keep downloads small. Their checksums are in `ANDROID-SHA256SUMS`.

Size-focused Rust builds use `-Oz`, full LTO, one code generation unit and symbol
stripping. Linux, macOS and Windows CLI downloads use `panic=abort`; a panic
terminates the process. Android retains unwinding for standalone operation
without a Java application context. On
Apple Silicon, the CLI decreased from 16.7 MB to about 3.7 MB before compression.
Native library builds finish Rust LTO before linking into Swift or JNI, removing
embedded LLVM bitcode from packaged archives. Normal SDK releases retain panic
unwinding. The SwiftPM SDK archives and `SHA256SUMS` remain included.
